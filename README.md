Proyecto Cine
Aplicación de reserva de boletos de cine.

Credenciales de Acceso:
El programa tiene cargado un admin por default, para ingresar como admin escribe lo siguiente:
Correo: admin@mail.com
Password: 123
En caso de querer ingresar como cliente debes de registrarte primero.

Cómo Ejecutar la Aplicación:
1. Dirígete a la sección de Releases en este repositorio.
2. Descarga el archivo .jar
3. Haz doble clic sobre el archivo descargado para ejecutar la aplicación.
